# Raquel Fátima · Tráfego Pago

Site pessoal da Raquel Fátima, estrategista de tráfego pago (Meta Ads, Google Ads, Google Meu Negócio, sites, landing pages, CRM e automações).

## Estrutura

```
index.html            página principal
assets/css/style.css  cores, fontes e layout
assets/js/main.js     animações, modo "explica fácil / técnico" e formulário
assets/img/           foto e ícone do site
robots.txt            orientação para o Google
sitemap.xml           mapa do site para o Google
llms.txt              resumo do site para IAs (ChatGPT, Gemini, Perplexity)
```

## Antes de publicar

1. Em `assets/js/main.js`, preencha `var WHATSAPP = "";` com o número (55 + DDD + número, só dígitos).
2. Em `robots.txt`, `sitemap.xml` e `llms.txt`, troque `SEU-DOMINIO` pelo endereço do site
   (ex.: `seuusuario.github.io/raquel-trafego-pago` ou o seu domínio próprio).

## Publicar no GitHub Pages

Settings → Pages → Branch `main`, pasta `/ (root)` → Save.
